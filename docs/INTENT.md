# INTENT — 왜 만드는가

## 배경

연구실은 Backend.AI 25.19(오픈소스)로 GPU 서버를 운영합니다. 현재 두 가지 문제가 있습니다.

1. **GPU를 장 단위로만 나눌 수 있습니다.** 오픈소스 `cuda` 플러그인은 `cuda.device`(1장, 2장…)만
   지원합니다. 작은 실험이나 추론에도 GPU 한 장을 통째로 잡게 됩니다. 소수 단위 할당(fGPU)은
   Lablup 엔터프라이즈 플러그인(Virtual CUDA API)이 있어야 하는데, 유료라 쓸 수 없습니다.
2. **협의로 나눠 받은 GPU가 밤새 놉니다.** 연구 시급도에 따라 사람별로 GPU를 배정하는데, 배정받은
   사람이 세션을 켜 둔 채 자면 그 GPU는 아무도 못 씁니다. 그렇다고 세션을 강제로 끄면 Jupyter 커널
   상태, 메모리에 올린 모델이 날아가서 반발이 큽니다.

## 목표

### G1. 부분 GPU(fGPU) 할당 — `cuda_frac` 가속기 플러그인

- Backend.AI가 `cuda.shares` 슬롯으로 `0.25`, `0.5`, `1.5` 같은 소수 GPU를 할당하게 합니다.
- 할당량은 **실제로 강제**합니다. 0.5를 받은 세션은 GPU 메모리의 절반만 보이고, SM 사용률도 대략
  절반으로 제한됩니다. 강제는 오픈소스 HAMi-core(`libvgpu.so`)가 담당합니다.
- 사용자는 코드를 고치지 않습니다. WebUI에서 평소처럼 fGPU 값을 고르면 됩니다.

### G2. 놀고 있는 GPU 빌려주기 — `labgpu-spot` 컨트롤러

- 소유자의 세션을 **끄지 않고**, 소유자가 GPU를 안 쓰는 동안에만 그 GPU를 스팟 작업에 빌려줍니다.
  (소유자 세션과 스팟 컨테이너가 같은 GPU를 **중복으로** 씁니다.)
- 소유자가 GPU를 다시 쓰기 시작하면 **즉시 회수**합니다. 스팟은 SIGTERM → 짧은 유예 → 종료되고,
  대기열로 돌아가 나중에 다시 실행됩니다.
- 스팟은 CPU를 낮은 우선순위로 겹쳐 쓰고, RAM은 명확한 상한 안에서만 쓰며, 메모리가 부족하면
  **스팟이 먼저 죽습니다.**

## 성공 기준

| # | 기준 |
|---|---|
| S1 | WebUI에서 `0.5` fGPU 세션을 만들면 컨테이너 안에서 GPU 메모리가 약 절반으로 보이고, 그 이상 할당하면 CUDA OOM이 납니다. |
| S2 | 소유자 세션이 N분(기본 30분) 동안 GPU를 안 쓰면, 대기 중인 스팟 작업이 그 GPU에서 자동으로 시작됩니다. |
| S3 | 소유자가 GPU 작업을 다시 시작하면 수십 초 안에 스팟이 회수되고, 소유자 작업은 실패하지 않습니다. |
| S4 | 회수된 스팟 작업은 대기열로 돌아가 다른 빈 GPU에서 이어서(체크포인트로) 실행됩니다. |
| S5 | 컨트롤러를 끄거나 죽여도 Backend.AI와 소유자 세션은 영향을 받지 않습니다. |

## 범위 밖 (지금은 하지 않음)

- **MIG / NVIDIA vGPU.** 하드웨어·라이선스 기반 분할은 다루지 않습니다.
- **강한 격리.** 같은 GPU를 쓰는 프로세스끼리는 GPU 오류(Xid)가 서로 번질 수 있습니다. 신뢰할 수
  있는 연구실 사용자끼리라는 전제로 받아들입니다.
- **Backend.AI 스케줄러 통합.** v1의 스팟은 Backend.AI **밖에서** `docker run`으로 실행합니다
  (대화에서 정한 "B안"). 그래서 WebUI와 Backend.AI 사용량 통계에는 스팟이 보이지 않습니다.
  Backend.AI 슬롯(`cuda.spot` 등)으로 편입하는 "A안"은 B안이 검증된 뒤 검토합니다.
- **크레딧 제도, Slack 알림, 대시보드.** 운영 정책이 정해지면 추가합니다. 데이터(작업 기록)는 v1부터
  남겨 둡니다.
- **여러 GPU를 쓰는 스팟 작업.** v1 스팟 작업은 GPU 1장만 씁니다.

## 설계 원칙 요약

1. **소유자 우선.** 스팟 때문에 소유자가 손해를 보면 안 됩니다.
2. **모르면 빌려주지 않는다.** 측정이 실패하거나 정체를 모르는 프로세스가 있으면 빌려주지 않고,
   빌려준 것도 회수합니다.
3. **강제할 수 없으면 나누지 않는다.** HAMi-core가 없으면 fGPU를 끄고 장 단위로 돌아갑니다.
4. **업스트림은 고치지 않는다.** 엔트리 포인트, etcd 설정, Docker 라벨 같은 공개 확장 지점만 씁니다.
